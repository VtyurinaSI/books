# Книги по программированию

Крупные книги разделены на самостоятельные PDF без уменьшения разрешения изображений. Конвертации из DjVu выполнены со сжатием без потерь. Все страницы сохранены в исходном порядке, без пропусков и повторов. Читайте файлы по числовому префиксу.

Страуструп разделён по частям книги, Липпман и Уильямс — по главам; большие приложения Уильямса — по разделам. Джосаттис разделён по главам и разделам исходного электронного оглавления. Раздел может начинаться на предыдущей странице: страницы не разрезались.

Все файлы меньше 50 МиБ. Загружайте через Git (например, Visual Studio), а не через веб-форму. Диапазоны ниже — номера страниц исходного PDF, считая первую страницу за 1; печатная нумерация может отличаться.

## Состояние исходников

Повреждённые PDF Джосаттиса и Липпмана заменены проверенными конвертациями из новых DjVu. Проверены все страницы обеих книг; ранее обнаруженные повреждения отсутствуют. Отчёты: [Джосаттис](DJOSATTIS-CHECK.md), [Липпман](LIPPMAN-CHECK.md). Остальные книги полностью на повреждения не проверялись.

## Первая загрузка

Для отправки книг небольшими партиями используйте скрипт ниже. Повторный запуск пропускает уже закоммиченные файлы без изменений.
После замены Джосаттиса и Липпмана общий объём PDF составляет около 1,3 ГиБ. Скрипт ниже отправляет файлы партиями до 45 МиБ;
у GitHub есть [лимит 2 ГиБ на одну отправку](https://docs.github.com/en/get-started/using-git/troubleshooting-the-2-gb-push-limit).

В PowerShell из этой папки выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\UPLOAD-BOOKS.ps1 -Upload
```

Скрипт создаст новые коммиты и отправит книги партиями до 45 МиБ.
Без параметра `-Upload` он только покажет количество файлов и партий.
При сетевой ошибке можно запустить скрипт повторно.
