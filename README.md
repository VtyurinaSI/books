# Книги по программированию

16 книг по C++ и разработке программного обеспечения. Крупные книги разделены по частям, главам и разделам; читайте PDF внутри папок по числовому префиксу.

Названия оформлены как `Фамилия И. - «Название», издание, год`. Номер издания указан, если он обозначен в книге. Для двух PDF без выходного года используется пометка «год не указан».
